Bu repo İBB Ümraniye Erkek Öğrenci Yurdu'nda kalan ve İETT 15SD hattını kullanmak zorunda olan öğrenci arkadaşlarımın, sık değişen otobüs saatlerinden haberleri olması için oluşturulmuştur.

1- Telefonunuza ntfy uygulamasını indirin.
2- Batarya tasarrufu ayarını güncelleyin.
3- Yeni bir kanal ekleyin, kanal adına "15sd-bayraktar-evobabax3535" yazın.
4- Instant Notifications ayarını aktive edin.
5- https://iett.istanbul/RouteDetail?hkod=15SD Sitesi güncellendikçe telefonunuza bildirim gelecektir.
